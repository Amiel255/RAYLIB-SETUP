# RAYLIB-SETUP

## Neon Drift
A fast-paced arena survival game built with [raylib](https://www.raylib.com/). Dash through enemy swarms, upgrade your firepower, and chase high scores.

### Features
- Mouse-aimed shooting with optional spread upgrade
- Dash mechanic with invulnerability frames
- Multiple enemy archetypes (chaser, shooter, tank)
- Power-ups for healing, dash refresh, slow motion, and wider fire pattern
- Particle effects, parallax starfield, score and best-score tracking
- Menu, pause, and game-over screens

### Building
Ensure `raylib` is installed on your system, then run:
```bash
make
```

### Running
```bash
./neon_drift
```
Use `make run` to build and start the game in one command.
